# Credits

## Sound effects
All made by the game itself: `bin/sfx.mjs` synthesises them (oscillators and filtered noise) into
`packages/foundations/sound/asset/sfx/`. No outside sources. Replace a wav (same name) to change a sound,
or add versions and list them in `sfx.json`.

## Music
The songs the owner drops in `asset/` (see `songs.json`). Add each song's source and licence here.

## Code
Built on papit (`@papit/*`). No other runtime dependencies.
