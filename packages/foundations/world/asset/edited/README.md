# Hand edited models

A `.glb` here, as `<group>/<name>.glb` (e.g. `buildings/bank.glb`), replaces the converted one in `asset/models`
the next time `node bin/models.mjs` runs, as it is. Keep vertex colours only, no textures, the ground at y 0,
the front to +z. Start from the file in `asset/models` (already turned outward and cut down) or from
pap-adventure's original.
